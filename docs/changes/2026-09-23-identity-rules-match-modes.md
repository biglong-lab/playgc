## 身份規則（一致原則）

**需要身份才算數的東西，訪客完成時先不寫，登入認領那一刻補寫**：

| 項目 | 訪客完成時 | 登入認領時 |
|---|---|---|
| 場次 / 進度 | 照寫（認領的依據） | 搬到正式帳號 |
| 排行榜 | 不寫 | 補寫（正式帳號顯示名） |
| 成就 | 不寫 | 補跑解鎖 |
| 獎勵券 | 不發 | 補觸發獎勵規則 |
| 隊伍戰績 | 照寫（隊伍紀錄、非個人） | — |

## 競賽 / 接力盤點（改前）

- 後端 API 大致齊全；前端只接到「建賽 → 加入 → 開賽 → 導向遊戲頁」
- 未接：分數回報、即時排名、結束賽事、結算排名、接力分段 / 交棒
- 問題：建立者不在參賽者內；任何登入者都能結束賽事；分數在非進行中也收；WS 轉播未驗證；
  回到大廳找不回賽事；接力段落沒有對應遊戲頁面
- 線上與本地皆 0 款競賽 / 接力遊戲、0 筆賽事 → 改動不影響現有玩家
